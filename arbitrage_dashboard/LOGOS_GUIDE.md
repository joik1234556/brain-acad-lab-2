# Руководство по размещению логотипов / Logo Placement Guide

---

## 1. Логотип сайта в браузерной вкладке (favicon)

**Что это:** маленькая иконка, которая отображается на вкладке браузера рядом с названием сайта.

**Куда класть:**
```
arbitrage_dashboard/
└── static/
    └── mmua-logo.svg   ← заменить этот файл своим логотипом
```

**Поддерживаемые форматы:** `.svg` (рекомендуется), `.png`, `.ico`

Если хотите использовать `.png` или `.ico` вместо `.svg`, замените строку в `app.py`:
```html
<!-- было -->
<link rel="icon" type="image/svg+xml" href="/static/mmua-logo.svg"/>

<!-- стало (пример для PNG) -->
<link rel="icon" type="image/png" href="/static/favicon.png"/>
```

---

## 2. Логотип сайта в шапке страницы (левый верхний угол)

**Что это:** логотип, который отображается слева вверху рядом с названием «Arbitrage Insights».

**Куда класть:**
```
arbitrage_dashboard/
└── static/
    └── mmua-logo.svg   ← тот же файл, что и для вкладки
```

> Один файл `static/mmua-logo.svg` используется и как favicon (иконка вкладки), и как логотип в шапке.  
> Достаточно заменить только его — оба места обновятся автоматически.

**Рекомендуемый размер:** квадрат, не менее 64×64 пикселей.

---

## 3. Логотипы бирж (MEXC, Bybit, BingX)

**Что это:** небольшие иконки бирж, которые отображаются рядом с названием биржи в таблице и в переключателях фильтра.

**Куда класть:**
```
arbitrage_dashboard/
└── assets/
    └── logos/
        ├── mexc.svg    (или mexc.png)
        ├── bybit.svg   (или bybit.png)
        └── bingx.svg   (или bingx.png)
```

**Правила именования файлов** (регистр не важен):

| Биржа | Допустимые имена файлов |
|-------|------------------------|
| MEXC  | `mexc.svg`, `mexc.png`, `mexc.jpg`, `mexc.webp` |
| Bybit | `bybit.svg`, `bybit.png`, `bybit.jpg`, `bybit.webp` |
| BingX | `bingx.svg`, `bingx.png`, `bingx.jpg`, `bingx.webp` |

**Поддерживаемые форматы:** `.svg`, `.png`, `.jpg`, `.jpeg`, `.webp`

Если файл с логотипом биржи не найден — вместо него просто ничего не отображается, ошибки не будет.

---

## Итоговая структура файлов

```
arbitrage_dashboard/
├── static/
│   └── mmua-logo.svg          ← логотип сайта (шапка + вкладка браузера)
└── assets/
    └── logos/
        ├── mexc.svg            ← логотип MEXC
        ├── bybit.svg           ← логотип Bybit
        └── bingx.svg           ← логотип BingX
```
