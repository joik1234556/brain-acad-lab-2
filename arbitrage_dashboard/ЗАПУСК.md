# Arbitrage Insights — Инструкция по запуску

## Требования

- Python **3.10+** (рекомендуется 3.11)
- Git
- (Опционально) Redis 7+ — для масштабирования и сохранения данных между перезапусками

---

## 1. Скачать проект

```bash
git clone https://github.com/joik1234556/brain-acad-lab-2.git
cd brain-acad-lab-2/arbitrage_dashboard
```

---

## 2. Создать и активировать виртуальное окружение

### Linux / macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### Windows (cmd)

```bat
python -m venv .venv
.venv\Scripts\activate
```

### Windows (PowerShell)

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

> ⚠️ Если PowerShell блокирует скрипт, выполните один раз:
> ```powershell
> Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
> ```

---

## 3. Установить зависимости

```bash
pip install -r requirements.txt
```

---

## 4. Запустить приложение

### Вариант A — простой запуск (рекомендуется для начала)

```bash
python app.py
```

Откройте в браузере: **http://127.0.0.1:8000**

---

### Вариант B — запуск через uvicorn (для разработки, с авторестартом)

```bash
uvicorn app:app --reload --host 127.0.0.1 --port 8000
```

---

### Вариант C — продакшн-запуск (несколько воркеров)

> Требует Redis (см. раздел 5).

```bash
uvicorn app:app --host 0.0.0.0 --port 8000 --workers 4
```

---

## 5. (Опционально) Запуск с Redis

Redis ускоряет работу при нескольких воркерах и сохраняет данные при перезапуске.

### 5.1 Установить и запустить Redis

#### Linux (Ubuntu/Debian)

```bash
sudo apt update && sudo apt install -y redis-server
sudo systemctl start redis
sudo systemctl enable redis   # автозапуск
```

#### macOS (Homebrew)

```bash
brew install redis
brew services start redis
```

#### Windows

Скачайте MSI-установщик:
https://github.com/microsoftarchive/redis/releases/latest

Или используйте Docker:

```bash
docker run -d --name redis -p 6379:6379 redis:7-alpine
```

### 5.2 Проверить, что Redis работает

```bash
redis-cli ping
# Ожидаемый ответ: PONG
```

### 5.3 Запустить приложение с Redis

```bash
# Linux / macOS
REDIS_URL=redis://localhost:6379/0 python app.py

# Windows cmd
set REDIS_URL=redis://localhost:6379/0
python app.py

# Windows PowerShell
$env:REDIS_URL = "redis://localhost:6379/0"
python app.py
```

> Если `REDIS_URL` не задан — приложение работает в in-memory режиме (без Redis).
> Сообщение `[Redis] Connected` в консоли подтвердит подключение.

## 6. Быстрый запуск одним файлом

### Windows — двойной клик

```
run_dashboard.bat
```

Батник сам создаст `.venv`, установит зависимости и запустит дашборд.

### macOS — двойной клик

```
run_local.command
```

(Убедитесь, что файл исполняемый: `chmod +x run_local.command`)
