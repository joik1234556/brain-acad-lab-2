# Arbitrage Insights — Инструкция по запуску

---

## 🚀 0. Быстрый старт — уже на сервере в нужной папке

Если вы уже подключены к серверу и находитесь в директории
`root@ubuntu-4gb-hel1-2:~/brain-acad-lab-2/arbitrage_dashboard#`
(или любом другом пути к `arbitrage_dashboard`):

### Первый запуск (новый сервер):

```bash
# 1. Системные пакеты (если ещё не установлены)
apt update && apt install -y python3.11 python3.11-venv git redis-server
systemctl enable --now redis

# 2. Виртуальное окружение и зависимости
python3.11 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt

# 3. Тест запуска (Ctrl+C чтобы остановить)
python app.py
# → Uvicorn running on http://127.0.0.1:8000

# 4. Открыть в браузере (подставьте IP вашего сервера):
# http://YOUR_SERVER_IP:8000  (нужно сначала открыть порт — см. шаг ниже)

# Открыть порт 8000 на время теста (вместо nginx):
ufw allow 8000/tcp
```

### Обновление кода (уже запущен):

```bash
# Находясь в ~/brain-acad-lab-2:
git fetch --all --prune
git pull --ff-only
git log -1 --oneline

# Затем в arbitrage_dashboard:
source .venv/bin/activate
pip install -r requirements.txt   # нужно только если изменились requirements
deactivate

# Перезапустить:
sudo systemctl restart arbitrage     # если запущен как systemd сервис
# ИЛИ: Ctrl+C в терминале где запущен, затем: source .venv/bin/activate && python app.py
```

### Запуск как постоянный сервис (рекомендуется):

```bash
# Создать systemd сервис:
cat > /etc/systemd/system/arbitrage.service << 'EOF'
[Unit]
Description=Arbitrage Insights Dashboard
After=network.target redis.service

[Service]
Type=simple
User=root
WorkingDirectory=/root/brain-acad-lab-2/arbitrage_dashboard
ExecStart=/root/brain-acad-lab-2/arbitrage_dashboard/.venv/bin/python app.py
Restart=always
RestartSec=5
Environment=ENV=production
Environment=HOST=127.0.0.1
Environment=PORT=8000
Environment=REDIS_URL=redis://localhost:6379/0
# Замените на реальный токен вашего бота:
Environment=TELEGRAM_BOT_TOKEN=<ВАШ_ТОКЕН_БОТА>
Environment=TELEGRAM_BOT_USERNAME=arbitrageinsights_bot

[Install]
WantedBy=multi-user.target
EOF

systemctl daemon-reload
systemctl enable --now arbitrage
systemctl status arbitrage

# Проверить:
curl -s http://localhost:8000/health
# Ожидается: {"ok":true,"uptime_s":...,"rows_cached":...}
```

### Nginx (чтобы сайт был доступен на порту 80):

```bash
apt install -y nginx
cat > /etc/nginx/sites-available/arbitrage << 'EOF'
server {
    listen 80;
    server_name _;   # замените на ваш домен если есть

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 3600;   # нужно для SSE (EventSource)
        proxy_buffering off;       # нужно для SSE
    }
}
EOF

ln -sf /etc/nginx/sites-available/arbitrage /etc/nginx/sites-enabled/
nginx -t && systemctl enable --now nginx

ufw allow OpenSSH && ufw allow 80/tcp && ufw enable
```

### Проверка нагрузки (2 vCPU / 4 GB RAM):

```bash
# Посмотреть CPU/RAM:
top -bn1 | head -5
free -h

# Посмотреть сколько SSE-подключений активно:
ss -tnp | grep 8000 | wc -l

# Лог сервиса:
journalctl -u arbitrage -n 50 --no-pager
```

---

> **Производительность на 2 vCPU / 4 GB RAM:**
> - Сервер поддерживает **50+ одновременных пользователей** без нагрузки благодаря:
>   - uvloop (2-3× быстрее asyncio на Linux)
>   - Pre-built `/api/data` кэш — O(1) ответ для каждого пользователя
>   - TCPConnector с keep-alive (не создаёт новые соединения каждый запрос)
>   - Обновление данных каждые 30 секунд (не каждую секунду)
>   - GZip сжатие ответов (-80% трафика)

```bash
python3 -m venv .venv
source .venv/bin/activate
```

## 4. Запустить приложение


```bash
uvicorn app:app --host 0.0.0.0 --port 8000 --workers 4
```

## 5. (Опционально) Запуск с Redis

Redis ускоряет работу при нескольких воркерах и сохраняет данные при перезапуске.

### 5.1 Установить и запустить Redis

#### Linux (Ubuntu/Debian)

```bash
sudo apt update && sudo apt install -y redis-server
sudo systemctl start redis
sudo systemctl enable redis   # автозапуск
```

#### macOS (Homebrew)

```bash
brew install redis
brew services start redis
```

#### Windows

Скачайте MSI-установщик:
https://github.com/microsoftarchive/redis/releases/latest

Или используйте Docker:

```bash
docker run -d --name redis -p 6379:6379 redis:7-alpine
```

### 5.2 Проверить, что Redis работает

```bash
redis-cli ping
# Ожидаемый ответ: PONG
```

### 5.3 Запустить приложение с Redis

```bash
# Linux / macOS
REDIS_URL=redis://localhost:6379/0 python app.py

# Windows cmd
set REDIS_URL=redis://localhost:6379/0
python app.py

# Windows PowerShell
$env:REDIS_URL = "redis://localhost:6379/0"
python app.py
```

> Если `REDIS_URL` не задан — приложение работает в in-memory режиме (без Redis).
> Сообщение `[Redis] Connected` в консоли подтвердит подключение.
