# Arbitrage Insights — Деплой на VPS (Linux сервер)

Это пошаговая инструкция для запуска сайта на Linux-сервере (Ubuntu/Debian).

> **Предполагается**: у вас есть VPS с Ubuntu 22.04 / 24.04 и root-доступ по SSH.

---

## 1. Подключиться к серверу по SSH

```bash
ssh root@89.167.53.202
```

Если у вас другой пользователь:

```bash
ssh ubuntu@89.167.53.202
```

---

## 2. Установить системные зависимости

```bash
# Обновить пакеты
sudo apt update && sudo apt upgrade -y

# Установить Python 3.11, git, nginx, ufw
sudo apt install -y python3.11 python3.11-venv python3-pip git nginx ufw curl
```

Проверить версию Python:

```bash
python3.11 --version
# Python 3.11.x
```

---

## 3. Скачать проект

```bash
cd /opt
sudo git clone https://github.com/joik1234556/brain-acad-lab-2.git
sudo chown -R $USER:$USER /opt/brain-acad-lab-2
cd /opt/brain-acad-lab-2/arbitrage_dashboard
```

---

## 4. Создать виртуальное окружение и установить зависимости

```bash
python3.11 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
deactivate
```

---

## 5. Проверить что сайт запускается вручную

```bash
cd /opt/brain-acad-lab-2/arbitrage_dashboard
source .venv/bin/activate
python app.py
# Должно появиться: INFO: Uvicorn running on http://0.0.0.0:8000
# Ctrl+C — остановить
deactivate
```

---

## 6. Настроить автозапуск через systemd

Создать файл сервиса:

```bash
sudo nano /etc/systemd/system/arbitrage.service
```

Вставить содержимое (нажмите `Ctrl+Shift+V`):

```ini
[Unit]
Description=Arbitrage Insights Dashboard
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/brain-acad-lab-2/arbitrage_dashboard
ExecStart=/opt/brain-acad-lab-2/arbitrage_dashboard/.venv/bin/python app.py
Restart=always
RestartSec=5
Environment=ENV=production

[Install]
WantedBy=multi-user.target
```

> Если вы используете не root, а другого пользователя (например `ubuntu`), замените `User=root` на `User=ubuntu`.

Сохранить: `Ctrl+O` → Enter → `Ctrl+X`

Включить и запустить сервис:

```bash
sudo systemctl daemon-reload
sudo systemctl enable arbitrage
sudo systemctl start arbitrage
```

Проверить статус:

```bash
sudo systemctl status arbitrage
# Должно быть: Active: active (running)
```

Посмотреть логи в реальном времени:

```bash
sudo journalctl -u arbitrage -f
```

---

## 7. Настроить Nginx (reverse proxy)

Nginx принимает запросы на порту 80 и перенаправляет их на FastAPI (порт 8000).

```bash
sudo nano /etc/nginx/sites-available/arbitrage
```

Вставить:

```nginx
server {
    listen 80;
    server_name 89.167.53.202;

    # Статические файлы напрямую через nginx (быстрее)
    location /static/ {
        alias /opt/brain-acad-lab-2/arbitrage_dashboard/static/;
        expires 7d;
        add_header Cache-Control "public, immutable";
    }

    # SSE (Server-Sent Events) — нужен специальный режим
    location /events {
        proxy_pass         http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header   Connection "";
        proxy_buffering    off;
        proxy_cache        off;
        proxy_read_timeout 3600s;
        proxy_set_header   Host $host;
        proxy_set_header   X-Real-IP $remote_addr;
    }

    # Все остальные запросы
    location / {
        proxy_pass         http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header   Upgrade $http_upgrade;
        proxy_set_header   Connection "upgrade";
        proxy_set_header   Host $host;
        proxy_set_header   X-Real-IP $remote_addr;
        proxy_set_header   X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 60s;
    }
}
```

Активировать конфиг:

```bash
sudo ln -s /etc/nginx/sites-available/arbitrage /etc/nginx/sites-enabled/
sudo nginx -t          # Проверить конфиг (должно быть: syntax is ok)
sudo systemctl restart nginx
sudo systemctl enable nginx
```

Теперь сайт доступен по адресу: **http://89.167.53.202**

## 8. Настроить firewall (ufw)

```bash
sudo ufw allow OpenSSH     # SSH — обязательно, иначе потеряете доступ
sudo ufw allow 80/tcp      # HTTP
sudo ufw allow 443/tcp     # HTTPS (для будущего SSL)
sudo ufw enable
sudo ufw status
```

## 9. (Опционально) Redis — для масштабирования

Redis ускоряет работу при нескольких воркерах:

```bash
sudo apt install -y redis-server
sudo systemctl enable redis-server
sudo systemctl start redis-server
redis-cli ping   # должен вернуть: PONG
```

Добавить Redis URL в systemd-сервис:

```bash
sudo nano /etc/systemd/system/arbitrage.service
```

Добавить строку в секцию `[Service]`:

```ini
Environment=REDIS_URL=redis://localhost:6379/0
```

Применить изменения:

```bash
sudo systemctl daemon-reload
sudo systemctl restart arbitrage
```

## 10. (Опционально) SSL / HTTPS бесплатно через Let's Encrypt

> Требует доменное имя (не работает на голом IP).  
> Если у вас есть домен — направьте его A-запись на `89.167.53.202`, затем:

```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d ваш-домен.com
sudo systemctl reload nginx
```

Сертификат обновляется автоматически.

## Шпаргалка — полезные команды

| Действие | Команда |
|---|---|
| Статус сайта | `sudo systemctl status arbitrage` |
| Перезапустить сайт | `sudo systemctl restart arbitrage` |
| Остановить сайт | `sudo systemctl stop arbitrage` |
| Логи сайта (последние 100 строк) | `sudo journalctl -u arbitrage -n 100` |
| Логи в реальном времени | `sudo journalctl -u arbitrage -f` |
| Статус nginx | `sudo systemctl status nginx` |
| Перезапустить nginx | `sudo systemctl restart nginx` |
| Проверить конфиг nginx | `sudo nginx -t` |
| Статус Redis | `sudo systemctl status redis-server` |
| Firewall — открытые порты | `sudo ufw status` |

## Краткая шпаргалка (весь деплой с нуля)

```bash
# Подключиться
ssh root@89.167.53.202

# Установить зависимости
apt update && apt install -y python3.11 python3.11-venv git nginx ufw

# Скачать проект
cd /opt && git clone https://github.com/joik1234556/brain-acad-lab-2.git
cd brain-acad-lab-2/arbitrage_dashboard

# Окружение
python3.11 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt && deactivate

# systemd-сервис
nano /etc/systemd/system/arbitrage.service     # вставить конфиг из раздела 6
systemctl daemon-reload && systemctl enable --now arbitrage

# Nginx
nano /etc/nginx/sites-available/arbitrage      # вставить конфиг из раздела 7
ln -s /etc/nginx/sites-available/arbitrage /etc/nginx/sites-enabled/
nginx -t && systemctl restart nginx && systemctl enable nginx

# Firewall
ufw allow OpenSSH && ufw allow 80/tcp && ufw enable

# Открыть в браузере:
# http://89.167.53.202
```
